## Ответы на вопросы
1. > Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?

В Dart необходимо явно указывать тип переменной. Это позволять находить ошибки типов заранее, до компиляции программы.

2. > Что означает `String?`? Чем отличается от `String`?

`String` может содержать строку, но не `Null`, `String?` может содержать и строку, и `Null`.

3. > Зачем в Dart `final`, если в Python можно просто договориться не менять переменную?

`final` позволяет программно закрепить значение переменной, которую нельзя изменять. Это защищает от человеческого фактора, когда человек может просто забыть о том, что переменную нельзя изменять или, если проект делается несколькими людьми, без лишних договорённостей понять, что переменную менять нельзя.

4. > Чем именованный параметр `{required String name}` отличается от позиционного? Приведите пример вызова.

Именнованный параметр перадаётся по имени, а позиционный - по порядку аргументов. `required` означает, что параметр обязателен, без него программа не скомпилируется.

#### Пример вызова функции с именнованными параметрами:
```dart
int sum({required int a, required int b}) {
  return a + b;
}

void main() {
  print(sum(a: 1, b: 2));
}
```

#### Пример вызова функции с позиционными параметрами:
```dart
int sum(int a,int b) {
  return a + b;
}

void main() {
  print(sum(1, 2));
}
```
